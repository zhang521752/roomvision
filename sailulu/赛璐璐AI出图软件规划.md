# 赛璐璐风格AI出图软件开发规划

## 项目概述

开发一款专注于赛璐璐风格的AI图像生成软件，通过模块化提示词系统，让用户能够轻松生成角色、场景、建筑、道具等元素的组合图像。

## ComfyUI集成方案

### 工作流调用流程
1. 用户在软件中完成选择
2. 软件生成提示词
3. 通过WebSocket连接ComfyUI
4. 加载预设的赛璐璐风格工作流
5. 替换工作流中的提示词节点
6. 提交工作流执行
7. 监听生成进度
8. 获取生成结果

### 预设工作流
- `cel_shading_basic.json` - 基础赛璐璐风格
- `cel_shading_detailed.json` - 高细节赛璐璐
- `cel_shading_mecha.json` - 机甲专用风格

## API中转层设计

### 统一API接口
```python
class ImageGeneratorAPI:
    def __init__(self):
        self.providers = {
            "midjourney": MidjourneyProvider(),
            "flux": FluxProvider(),
            "kling": KlingProvider(),
            "comfyui": ComfyUIProvider(),
            "sdxl": SDXLProvider()
        }
    
    async def generate(self, prompt, provider, params):
        """统一生成接口"""
        return await self.providers[provider].generate(prompt, params)
```

### 支持的模型提供商
| 提供商 | 接入方式 | 特点 |
|--------|---------|------|
| Midjourney | Discord API/中转 | 质量高，风格独特 |
| Flux | API调用 | 新兴模型，质量不错 |
| 可灵 | 官方API | 中文支持好 |
| ComfyUI | 本地WebSocket | 完全控制，可自定义工作流 |
| SDXL | 本地/API | 开源，灵活 |

## 关键特性

### 1. 智能提示词优化
- 根据选择自动调整权重
- 避免冲突的提示词组合
- 提供风格一致性建议

### 2. 批量生成
- 支持一次生成多张图片
- 可设置变体参数（种子、风格强度等）

### 3. 收藏和模板
- 保存常用组合为模板
- 一键应用预设模板

### 4. 历史记录
- 记录所有生成记录
- 支持搜索和筛选
- 可重新生成或修改后生成
