# 赛璐璐风格AI出图软件 - 提示词库数据结构设计

## 概述

本文档详细定义了赛璐璐风格AI出图软件中所有提示词库的数据结构。采用模块化JSON设计，支持中英文双语，便于扩展和维护。

## 数据结构设计原则

1. **模块化**：每个模块独立存储，便于单独更新
2. **双语支持**：所有标签包含中文和英文版本
3. **层级结构**：支持多级分类，便于精确选择
4. **可扩展性**：预留扩展字段，支持未来功能
5. **权重支持**：可为不同选项设置默认权重

## 提示词生成规则

### 1. 提示词模板结构

```
[质量前缀], [风格描述], [角色描述], [场景描述], [道具描述], [光影描述], [镜头描述], [特殊需求]
```

### 2. 权重系统

- 默认权重：1.0
- 重要元素可设置更高权重（1.1-1.5）
- 使用括号语法：`(element:weight)`

### 3. 提示词组合规则

```python
def generate_prompt(selections):
    prompt_parts = []
    
    # 1. 质量前缀（必选）
    prompt_parts.append("masterpiece, best quality, cel-shading anime style")
    
    # 2. 风格描述
    if selections.get("style"):
        prompt_parts.append(selections["style"]["prompt_en"])
    
    # 3. 角色描述
    character_parts = []
    if selections.get("character"):
        char = selections["character"]
        if char.get("gender"):
            character_parts.append(char["gender"]["prompt_en"])
        if char.get("age"):
            character_parts.append(char["age"]["prompt_en"])
        # ... 其他属性
    prompt_parts.append(", ".join(character_parts))
    
    # 4. 场景描述
    if selections.get("scene"):
        prompt_parts.append(selections["scene"]["prompt_en"])
    
    # 5. 道具描述
    if selections.get("props"):
        prompt_parts.append(selections["props"]["prompt_en"])
    
    # 6. 光影描述
    if selections.get("lighting"):
        prompt_parts.append(selections["lighting"]["prompt_en"])
    
    # 7. 镜头描述
    if selections.get("camera"):
        prompt_parts.append(selections["camera"]["prompt_en"])
    
    # 8. 特殊需求
    if selections.get("custom"):
        prompt_parts.append(selections["custom"])
    
    return ", ".join(filter(None, prompt_parts))
```

1. 在对应模块的JSON文件中找到相应类别
2. 按照现有格式添加新选项
3. 确保包含中英文版本
4. 设置合适的权重（可选）

1. 在对应模块的JSON文件中添加新类别
2. 定义类别元数据（标签、图标等）
3. 添加选项列表
4. 更新提示词生成器以支持新类别

### 添加新模块

3. 在提示词生成器中注册新模块
4. 在UI中添加对应面板
