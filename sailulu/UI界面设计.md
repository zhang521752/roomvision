# 赛璐璐风格AI出图软件 - UI界面设计

## 概述

本文档详细设计了赛璐璐风格AI出图软件的用户界面，包括主界面布局、各功能面板设计、交互流程和视觉规范。

## 设计原则

1. **简洁直观**：界面清晰，操作简单
2. **模块化布局**：功能分区明确，便于快速定位
3. **实时预览**：提示词和图像预览实时更新
4. **响应式设计**：适应不同屏幕尺寸
5. **一致性**：统一的视觉风格和交互模式

## 核心交互组件

### 1. 标签选择器 (TagSelector)

```
┌─────────────────────────────────────┐
│  标签选择器组件                      │
├─────────────────────────────────────┤
│  功能特性:                          │
│  - 单选/多选模式                    │
│  - 可配置最大选择数量               │
│  - 支持搜索过滤                     │
│  - 选中状态高亮显示                 │
│  - 支持图标和文字                   │
│  - 支持颜色块                       │
└─────────────────────────────────────┘

实现代码:
class TagSelector(QWidget):
    selection_changed = pyqtSignal(list)
    
    def __init__(self, options, multi_select=False, max_select=None):
        super().__init__()
        self.options = options
        self.multi_select = multi_select
        self.max_select = max_select
        self.selected = []
        self.init_ui()
    
    def init_ui(self):
        layout = FlowLayout()
        for option in self.options:
            btn = TagButton(option)
            btn.clicked.connect(lambda checked, opt=option: self.on_tag_clicked(opt))
            layout.addWidget(btn)
        self.setLayout(layout)
    
    def on_tag_clicked(self, option):
        if self.multi_select:
            if option in self.selected:
                self.selected.remove(option)
            elif len(self.selected) < self.max_select:
                self.selected.append(option)
        else:
            self.selected = [option]
        self.selection_changed.emit(self.selected)
```

### 2. 颜色选择器 (ColorSelector)

```
┌─────────────────────────────────────┐
│  颜色选择器组件                      │

class ColorSelector(QWidget):
    color_changed = pyqtSignal(str)
    
    def __init__(self, preset_colors=None):
        super().__init__()
        self.preset_colors = preset_colors or []
        self.selected_color = None
        self.init_ui()
    
    def init_ui(self):
        layout = QHBoxLayout()
        for color in self.preset_colors:
            btn = ColorButton(color)
            btn.clicked.connect(lambda c=color: self.on_color_selected(c))
            layout.addWidget(btn)
        
        custom_btn = QPushButton("自定义")
        custom_btn.clicked.connect(self.show_color_dialog)
        layout.addWidget(custom_btn)
        
        self.setLayout(layout)
    
    def on_color_selected(self, color):
        self.selected_color = color
        self.color_changed.emit(color)
```

    if width < BREAKPOINTS["small"]:

## 总结

本UI界面设计遵循以下原则：

1. **用户友好**：简洁直观的界面，降低学习成本
2. **模块化设计**：功能分区明确，便于快速定位和操作
3. **实时反馈**：提示词和预览实时更新，所见即所得
4. **灵活配置**：支持多种选择模式和自定义选项
5. **响应式布局**：适应不同屏幕尺寸，提供最佳体验

通过这套UI设计，用户可以轻松地通过模块化选择生成高质量的赛璐璐风格提示词，并调用各种AI模型生成图像。
